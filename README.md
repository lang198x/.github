# Lang198x organisation context

This repository holds the public organisation profile, shared foundation
documents and canonical org-container agent context. The [hub](https://github.com/lang198x/lang198x) coordinates language projects.
The first [AMOS kit](https://github.com/lang198x/amos) provides a bounded
parser/checker and reusable highlighting.

The [ownership decision](https://github.com/stevehill1981/198x/blob/dd9bdfa0cf272fb87763c15afa45f6b35e0978e2/decisions/lang198x-language-tools.md)
defines the boundary with the other 198x siblings.
